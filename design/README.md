# design/ — Claude Design canvas manbasi

Bu papka Claude Design canvas'idagi dizaynning to'liq nusxasi (vizual ma'lumot uchun).

- Main.dc.html — desktop/web uchun to'liq interaktiv prototip (barcha ekranlar mantiqi shu yerda: grafik hisoblash, davomat, shlagbaum holatlari, o'chirish qoidalari).
- Mobile.dc.html — Android prototipi.
- S02..S30 — desktop ekranlari (Main.dc.html'ga yo'naltiruvchi yupqa fayllar), M01..M11 — Android ekranlari.
- DesignSystem.dc.html — ranglar, shriftlar, tugmalar.
- canvas.json — artboardlarning joylashuvi.

QOIDA: Bu fayllar Claude Design formatida (.dc.html), ularni to'g'ridan-to'g'ri ilovaga ko'chirib bo'lmaydi — faqat ko'rinish, rang, o'lcham va xatti-harakat namunasi sifatida o'qing.
Dizayn va ../UI-SPEC.md o'rtasida farq bo'lsa, ../UI-SPEC.md va ../CLAUDE.md ustun.
Canvas'da hali yo'q (lekin UI-SPEC.md'da bor) elementlar: kamerada "Ulanish testi" va "Tanish qayerda" tanlovi, Davomatda "Tuzatish"/"Sabab qo'shish", ANPR ro'yxatini tahrirlash, "Parolni tiklash", xaritada "Rejani yuklash"/"Hududni chizish", pleyerda ±10 soniya. Ularni UI-SPEC.md bo'yicha quring.
